# Statement と Lean の監査用対応メモ（草案）

以下の定義名と `u=s/2` の規約は `lean/` のComparator参照側を説明しています。
2026-10-17に書き直したFC提出用草案は独立した記述で、`epstein` の引数を距離指数
`s` にそろえています。その対数係数は `s` で直接微分します。FC草案の同値性は未監査です。

公開候補の最終結果は、球面 S²・S⁸・S²⁴ の正の Riesz 指数、負の Riesz 指数、
対数エネルギー、cap discrepancy の計12定理と、S⁸ の s=4・s=2 の2定理です。
論文の式番号と各 Lean 名の対応は
[TARGET-CORRESPONDENCE.md](../lean/comparator/TARGET-CORRESPONDENCE.md) にあります。

照合した規約は次のとおりです。

| 項目 | 自然言語・Lean に共通する意味 |
|---|---|
| 球面 | R^(d+1) 内の半径1の球面。d は球面の次元。 |
| 点配置 | 相異なる N 点。`Fin N ↪ Sphere d` の単射条件で表す。 |
| 距離と和 | ユークリッドの弦距離。対角を除く順序付きペアの和。 |
| 測度 | 背景エネルギーは一様確率測度。面積 A_d は正規化前の面積。 |
| 最適化 | 0<s<d は infimum、−2<s<0 は supremum、対数は infimum。 |
| 極限 | N は自然数全体で無限大へ。部分列や配置の分離条件は付けない。 |
| 格子の尺度 | 三角格子、E8、Leech はいずれも covolume 1。 |
| ゼータ関数 | 論文は距離の指数 s、Lean の複素引数は u=s/2。 |
| 対数係数 | u で微分するため、S²・S²⁴ の式には 1/2 が付く。S⁸ は論文と同じ展開済みの定数。 |
| cap discrepancy | 点数を N で割り、二乗を積分してから平方根。高さ測度は [−1,1] 上の dt。 |
| S⁸ の s=2 | ゼータ積をそのまま代入せず、除去可能点の値 120 ζ′(−2) を別定理で扱う。 |

`FCTargetDefinitions.lean` は Mathlib のみを import し、球面、測度、エネルギー、
格子の整数行列、theta 積分による解析接続を明示しています。
`FCBridge.lean` は、これらと既存の証明ライブラリの定義が一致することを証明します。
`Challenge.lean` と `FCSolution.lean` の14定理の型は、文字列を正規化した比較でも
一致しています。実行したチェックの成否は [README.md](README.md) と
`work-status.json` に分けて記録しています。

論文の中間入力は「すべての正の尺度での格子 Gaussian minorant」です。
E8・Leech の Lean 証明は β≠1 の格子証明と尺度変更を使い、最終結果に必要な
球面上の全尺度を得ています。最終14定理に β≠1 という仮定はありません。
この公開候補で、全尺度の格子 minorant 自体を証明したとは表示していません。
